# Synthetic Wafer Data — Schema Reference

All fixture files are generated by `src/data/generate_data.py` with `random.seed(42)`.
They are committed under `src/data/fixtures/` and are the sole data source for the
backend, pattern detector, ML risk model, and watsonx.ai LLM context.

---

## 1. `wafer_lots.csv` — 500 rows

One row per wafer lot processed through a single fab process step.

| Column | Type | Example | Description |
|---|---|---|---|
| `lot_id` | string | `W2401-0001` | Unique lot identifier. Format: `W{YYMM}-{seq:04d}`. |
| `node` | string | `3nm` | Technology node. Values: `3nm`, `5nm`. |
| `process_step` | string | `etch` | Fab process step. Values: `litho`, `etch`, `deposition`, `cmp`, `diffusion`, `implant`. |
| `tool_id` | string | `ETCH-03` | Equipment tool used. Step-specific IDs (see Tool Inventory below). |
| `recipe_id` | string | `R-ETH-04` | Process recipe applied. Step-specific IDs. |
| `operator` | string | `op_alice` | Fab operator who ran the lot. Values: `op_alice`…`op_eve`. |
| `wafer_count` | integer | `25` | Number of wafers in the lot (always 25). |
| `yield_pct` | float | `91.85` | Final die yield percentage (0–100). **Target variable.** |
| `low_yield_flag` | integer | `0` | `1` if `yield_pct < 82.0`, else `0`. Classification label. |
| `timestamp` | ISO-8601 string | `2024-01-01T06:00:00` | Lot start time. Lots are spaced ~4 h apart starting 2024-01-01. |

### Tool Inventory

| Process Step | Tool IDs |
|---|---|
| litho | LIT-01, LIT-02, LIT-03 |
| etch | ETCH-01, ETCH-02, ETCH-03 |
| deposition | DEP-01, DEP-02, DEP-03 |
| cmp | CMP-01, CMP-02 |
| diffusion | DIFF-01, DIFF-02 |
| implant | IMP-01, IMP-02 |

## 3. `defect_reports.csv` — ~3 300 rows

One row per individual defect observed on a wafer. Multiple defects per lot are expected.

| Column | Type | Example | Description |
|---|---|---|---|
| `defect_id` | string | `D-0000001` | Unique defect record ID. |
| `lot_id` | string | `W2401-0001` | Foreign key to `wafer_lots.lot_id`. |
| `wafer_id` | string | `W2401-0001-W07` | Wafer within the lot. Format: `{lot_id}-W{nn}`. |
| `tool_id` | string | `ETCH-03` | Tool associated with the lot that produced this defect. |
| `process_step` | string | `etch` | Process step when the defect occurred. |
| `defect_type` | string | `particle` | Defect category. Values: `particle`, `scratch`, `void`, `bridge`, `etch_pit`, `patterning_defect`. |
| `defect_density` | float | `0.2831` | Defects per cm2 on the wafer. Higher = worse. |
| `x_coord_mm` | float | `-42.15` | X position of the defect on the wafer (radius 149 mm). |
| `y_coord_mm` | float | `88.70` | Y position of the defect on the wafer (radius 149 mm). |
| `timestamp` | ISO-8601 string | `2024-01-01T07:34:00` | Defect detection timestamp. |

### Defect Type Descriptions

| Defect Type | Description |
|---|---|
| `particle` | Contamination particles deposited on the wafer surface. Primary yield killer in P1/P2 patterns. |
| `scratch` | Physical surface damage from handling or CMP. |
| `void` | Missing fill material in deposition layers. |
| `bridge` | Unintended conductor connections between adjacent features. |
| `etch_pit` | Localised over-etch damage from temperature/pressure excursions. |
| `patterning_defect` | Lithography alignment or dose error producing mis-patterned features. |

## Injected Low-Yield Patterns

The generator deliberately embeds four statistically detectable patterns that the
pattern detector and ML model are expected to discover:

### P1 — ETCH-03 Tool Degradation (lots 201-500)

- **Signal**: `etch_temp_c` on tool `ETCH-03` elevated ~12 degC above nominal (188 degC vs 175 degC).
- **Cause**: Simulates a degraded chamber heating element causing thermal drift.
- **Effect**: `yield_pct` reduced by ~20 pp (Gaussian, mean=20, sigma=3).
- **Detection**: Correlation between `etch_temp_c` and `yield_pct` for `tool_id=ETCH-03`.

### P2 — DEP-02 + R-NIT-07 Recipe Interaction

- **Signal**: `rf_power_w` on tool `DEP-02` with recipe `R-NIT-07` elevated ~45 W above nominal (425 W vs 380 W).
- **Cause**: Simulates a recipe-tool resonance causing RF power spikes.
- **Effect**: `yield_pct` reduced by ~15 pp (Gaussian, mean=15, sigma=3).
- **Detection**: Correlation between `rf_power_w` and `yield_pct` filtered by `recipe_id=R-NIT-07`.

### P3 — Particle Contamination on Low-Yield Lots

- **Signal**: `defect_density` of type `particle` is 4x higher on low-yield lots (mean 0.31 vs 0.07 /cm2).
- **Cause**: Simulates fab particle events that correlate with both P1 and P2 yield drops.
- **Effect**: Indirect yield driver (co-occurs with P1/P2 root causes).
- **Detection**: Average `defect_density` by `defect_type=particle` grouped by `low_yield_flag`.

### P4 — ETCH-01 Pressure Drift (lots 351-500)

- **Signal**: `etch_pressure_mtorr` on tool `ETCH-01` drifts upward linearly at ~0.012 mTorr/lot from lot 351.
- **Cause**: Simulates a gradual vacuum seal degradation.
- **Effect**: `yield_pct` reduced by ~7 pp (Gaussian, mean=7, sigma=2) — a mild but detectable drift.
- **Detection**: Time-series trend of `etch_pressure_mtorr` for `tool_id=ETCH-01` over lot sequence number.

## Cross-Dataset Consistency

- Every `lot_id` in `equipment_sensor_readings.csv` and `defect_reports.csv` exists in `wafer_lots.csv`.
- Every `tool_id` in all three files is consistent with the tool inventory above.
- Timestamps are monotonically increasing across lots; sensor/defect timestamps fall within the lot run window.
- All three files share the same 500 unique `lot_id` values.
